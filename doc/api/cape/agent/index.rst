
***************************************************
:mod:`cape.agent`: Agentic interface to CAPE
***************************************************

.. automodule:: cape.agent
    :members:

Interactive ``cape agentic`` sessions use the Textual interface when the
optional dependency and a capable terminal are available. Use
``--no-agent-tui`` to force the traditional readline interface. The
single-turn ``cape agent <prompt>`` command remains noninteractive.
